# Bouche Cousue

Jeu de poker coopératif en 3D, à jouer entre amis dans le navigateur (ordinateur ou téléphone).

Chacun classe sa main avec des jetons, sans jamais parler de ses cartes. Trois coffres ouverts : le gang gagne. Trois alarmes : tout le monde au poste.

Le jeu tient dans `index.html`. Le temps réel entre joueurs passe par Supabase Realtime.
